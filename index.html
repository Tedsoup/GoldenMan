The rules

  • Bazaar: insta-sell only (no buy orders or sell offers)
  • Bazaar buys: Booster Cookies only
  • Auction House: completely off-limits
  • Trading: co-op members only
  • NPC shops and the Dark Auction are fine

How to join

  1. Install the Golden Man mod (Fabric, Minecraft 26.2)
  2. Make a fresh SkyBlock profile (below level 7)
  3. Turn on every API setting: SkyBlock Menu → Settings → API Settings
  4. Press G → Start Golden Man. You're registered automatically.

What gets checked

  • All API settings are on
  • The run started on a profile below SkyBlock level 7
  • The Auction House was never used
  • Every co-op member is registered too

Statuses

  • Verified: everything checks out
  • Pending: something needs fixing (see the reasons)
  • Failed: a rule was broken. This is permanent.
Re-checked every hour.
